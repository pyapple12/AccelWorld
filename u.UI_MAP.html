总览：一扇窗，三个层级

主仪恒驻中央，抽屉从右侧进入，仪器坞固定在底部。先把这三个层级分清，后面每一页都只是抽屉里的内容替换。

B1 舞台页头 产品标 / 名 / 副题 / 日期
B3 星盘 刻度 / 双针 / 金弧 / 四正位
B11 盘下读数 加速值 + 日序号 │ 现实值
B18 倍率条 6px 轨 + 亮白旋钮；不是滑杆
B25 农历 meta 行 农历 · 月相 · 财神，一条文本
C1 坞带 窗口底部 64px 区域
C2 坞胶囊 五页 + 设置；选中金下划线
D1 抽屉面板 右侧临时页面；不是浮窗
D2 抽屉页头 页面标题 + 关闭 ×
D7 抽屉内容区 页面各自滚动；内边距 20/8/16
D8 抽屉页脚 仅倒计时 / 世界 / 闹钟有

先记住三句话

  • 主仪是中央仪表区；时钟页只在讨论页面切换时用。
  • 抽屉是右侧临时页；设置也是抽屉，不是浮窗。
  • 仪器坞是底部胶囊；不要叫侧栏、底栏、导航栏。
01

时钟页 / 主仪

唯一恒驻的页面。星盘是产品签名；读数在盘下，倍率条是 6px 短条，农历是一条 meta 行。窗口变矮（可用高 < 380）时退化为数字版。

图上编号

B1 舞台页头 52px（短窗 40）；产品标 / 名 / 副题 / 日期
B3 星盘 直径 180–560；96 刻度 + 四正位
B7 加速针 / 金针 3px；指向加速时刻 24h
B8 现实针 / 灰针 1.8px；长度为金针 62%
B6 金弧 两针间的较短弧；膨胀差
B11 盘下读数 加速 56 / 现实 24；限宽 640
B14 日序号 ≥24h 才显示“第 2 天”
B18 倍率条 宽 220–360，高 62；6px 轨
B25 农历 meta 行 一条 12px 文本，不是三个盒子
C2 坞胶囊 底部 560×56；选中金下划线

目测检查点

  • 金针与灰针在 rate=7.2 时应明显分开；两针重合是旧版缺陷。
  • 盘心没有 ×7.2；倍率值只在条右端出现一次。
  • “第 2 天”只在加速时间 ≥24h 时出现。
  • 农历/月相/财神是一条 meta 行，不应出现三个 chip 盒子。
02

倒计时页

抽屉页。Hero 卡只显示“最近的下一个目标”；列表只列其余目标，避免同一数字出现两次；添加表单固定在页脚，目标再多也够得着。

抽屉内部

D2 抽屉页头 标题“倒计时” + 关闭 ×
E2 Hero 卡 126px；只显示最近的下一个目标
E3 “下一个”标签 12/500 金色；不是页面标题
E7 近期节日 meta 行 一条 12px 文本；不是 chip 盒子
E8 其他目标区 hero 已排除；列表只列其余
E9 目标行卡 68px；名称/日期左，剩余右对齐
E12 目标行删除 Trash；两步武装（Check，4s）
E15 抽屉页脚 固定；名称 + 时刻 + 添加
E16 名称字段 Field：label 上置 + 1px 输入边
E17 时刻字段 HH:MM；格式错误同位红字
E18 添加按钮 88×32 ink 实底；不是金色

目测检查点

  • Hero 里的目标不应再出现在“其他目标”列表里。
  • 3 个目标时页脚仍固定可见；内容只在自己的滚动区滚。
  • 删除第一次点击变 Check（武装态），第二次才删除。
  • “近期节日”是文字行，不是三个独立 chip。
03

世界时钟页

抽屉页。城市行是 60px 紧凑行：名称、基准标记、昼夜、右对齐走时、删除。页脚只有一个下拉，选择即添加——没有“添加”按钮。

抽屉内部

F1 世界时钟页 页头“世界时钟”；坞标签“世界”
F2 城市行 60px；整行可点，点击设基准
F4 基准标记 左侧 2px 金线；只做状态标记
F5 基准 chip Pin + “基准”；52×18
F7 昼夜图标 Sun / Moon，14px；行宽 ≤280 跳过
F8 城市走时 24px digits；基准行更亮
F9 城市删除 Trash；仅城市数 >1 时显示
F10 添加城市页脚 标签 + 下拉；没有添加按钮
F11 城市下拉 Select；候选项排除已添加城市
F12 世界空态 “还没有城市 / 从下方添加…”

目测检查点

  • 基准不只靠金色：金线 + Pin + “基准”文字同时存在。
  • 删除城市至少保留 1 个；只剩 1 城时 Trash 消失。
  • 窄行（≤280 宽）跳过昼夜图标，避免压住走时。
  • 下拉选择即添加，不应再找一个“添加”按钮。
04

天气页

抽屉页。整页 ScrollArea，没有固定页脚。头行是城市 + 刷新；下面是错误/旧值、Hero 聚簇、三列指标、逐小时曲线、七日范围条、数据源。

抽屉内部

G2 天气头行 城市 + 刷新/加载
G3 城市下拉 150px；切换即刷新
G4 刷新按钮 Refresh 16px；加载时换 Spinner
G5 加载弧 16px、270°、600ms/圈；替换 G4
G6 错误行 danger 12px；说明原因
G7 重试 小按钮；强制刷新
G8 旧值提示 “显示上次数据 X°”
G9 Hero 聚簇 图标 + 温度 + 描述
G10 天气图标 34px；按 WMO code
G11 温度 44px digits
G13 三列指标 体感 / 湿度 / 风力
G15 逐小时区 标题 + 曲线 + 图外时间轴
G16 温度曲线 132px；无背景/轴；4 条淡线
G19 七日区 周范围 + 7 行
G21 七日行 22px；日期 / 条 / 低高
G25 低/高值 68px 右对齐；在 card_bg 上
G26 数据源行 Open-Meteo · 免费接口

目测检查点

  • 七日温度绝不在金色条上；值列固定 68px，右缘不裁。
  • 曲线没有矩形背景/边框；只有 4 条横向淡线。
  • 失败时旧值仍显示，错误行有“重试”。
  • 整页可滚；没有固定页脚，不要找“页脚”。
05

闹钟页

抽屉页。快捷添加是有边界的 chip；闹钟行 64px：开关、24px 时刻、标签·重复、删除；添加表单固定在页脚。

抽屉内部

H2 快捷添加标签 12/500 muted；不是分区标题
H3 快捷 chip 30px；有边界；不是通用 chip 组件
H4 闹钟行 64px；开关/时刻/标签·重复/删除
H5 闹钟开关 36×20；on=success 绿
H6 闹钟时刻 24px digits；关闭时降权
H7 标签 / 重复 14px；超宽省略 + tooltip
H8 闹钟删除 16px Trash；两步武装
H10 闹钟页脚 标签 + 时间 + 添加；恒占错误行
H11 标签字段 Field；label 上置
H12 时间字段 HH:MM；非法不发送
H13 添加按钮 88×32 ink 实底

目测检查点

  • 开关 on 是语义绿，不是品牌金；位置在右才是主信号。
  • 快捷 chip 有 1px 边界；不应是裸文本或金底 hover。
  • 关闭的闹钟整行降权，但仍可读、可重新开启。
  • 删除第一次点击变 Check，第二次才删除。
06

设置页

也是抽屉页，标题“设置”，副标题“外观 · 动效 · 关于”。不是一个右下角浮窗，也不是 modal。

抽屉内部

I1 设置抽屉 标题“设置” + 副标题；不是浮窗
I2 外观分区 16/600 + 12 muted + 1px 发丝
I3 主题行 只读；子夜星图（深色）
I4 动效分区 说明过渡范围
I5 减少动效行 左标签 + 说明；右开关
I6 减少动效开关 36×20；on=success 绿
I7 关于分区 版本 / 数据来源 / 字体
I8 版本行 只读；当前 0.6.4.1
I9 数据来源行 右端 Cloud 14px 轻提示
I10 字体行 MiSans（小米，免费商用）/ Bahnschrift
I11 设置页尾签 “加速世界 · 子夜星图”

目测检查点

  • 设置打开时，抽屉替换当前页内容，不叠在右下角。
  • 版本号只在“关于”里，不在窗口标题栏。
  • “减少动效”关掉后，hover/列表脉冲/toast 直取终态。
  • 没有“深色主题（实心桌面）”这类实现说明。

10

怎么把这些名字用在对话里

一条对账描述只需要三段：位置、元素、状态，再加现象。位置从大到小，用 > 分隔。 

页面/区域 > 子区域 > 元素 [状态]：现象

时钟页 > 星盘 > 现实针 [常态]：长度只有金针的 62%，看起来像短线
倒计时页 > 抽屉页脚 > 错误行 [错误]：红字出现时不应把添加按钮挤跳
天气页 > 七日 > 低/高值 [常态]：值在 card_bg 上，不压金条
闹钟页 > 闹钟行 > 开关 [开]：绿色 + 旋钮在右；位置是主信号
设置页 > 动效 > 减少动效 [开]：hover/列表脉冲/toast 直取终态
先认区域，再认元素。说“主仪”就不要再补“时钟页左边”；说“抽屉页脚”就不要说“底栏”。
同一页的两个文案要说明。“世界时钟页（坞项‘世界’）”比单说“世界页”清楚。
状态用方括号。[悬停]、[聚焦]、[武装]，不要用“点亮/高亮/激活”这类模糊词。
视觉缺陷说“现象”，不说“感觉”。“七日低温值被右缘裁掉”比“天气有点挤”可复现。
旧称保留在对照表。旧截图/旧报告里出现“侧栏/底栏/浮窗”时，用 §09 的表翻译，不要直接改历史记录。
新元素先登记。新增可见元素先在 u.UI_GLOSSARY.md 写主称、代码锚点、尺寸/状态，再写代码。
维护规则：改名时同步代码 /// 注释、w.study.md 3.7 节、README 使用说明、u.UI_GLOSSARY.md 与这份指南；不要只改一处。 术语表不替代设计评审，它只保证我们指同一个东西。
