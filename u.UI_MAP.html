先记住三句话

  • 主仪是中央仪表区；时钟页只在讨论页面切换时用。
  • 抽屉是右侧临时页；设置也是抽屉，不是浮窗。
  • 仪器坞是底部胶囊；不要叫侧栏、底栏、导航栏。
01

时钟页 / 主仪

唯一恒驻的页面。星盘是产品签名且任何高度都保留（最小 120）；读数在盘下，倍率条是 6px 短条，农历在页头右栏。窗口变矮时先压星盘，再按 560 界缩页头。

图上编号

B1 舞台页头 左日期盒 15.5 + 右农历盒 26.0（11.5×2+3），中线对齐；盒底 +5 +1 横线；高 560 分两行/一行，宽 560 分完整/精简
B3 星盘 12h：60 刻度 + 12/3/6/9 内侧（320 母版 20px，按 scale 缩放）
B7 加速针 / 黄针 3.2px；指向加速时刻 12h
B8 现实三针 时米白 / 分星紫 / 秒朱红
B6 金圈 加速日进度；CPU 实环 + GPU bloom
B11 盘下读数 第 NNN 天（第/N/天 三内盒中线对齐）+ 当天时间；现实 36px
B14 日序号 与时间同行；001 补零、固定三槽宽
B18 倍率条 宽 220–360，高 73.0；6px 轨 + 量化行；1–365
B25 农历 meta 行 已移除；农历在页头右栏
C2 坞胶囊 底部 56/44 两级；选中金下划线

目测检查点

  • 三针走现实 12h；黄针走加速 12h，rate=2 时应与时针明显分开，rate=1 时重合。
  • AM/PM 胶囊在盘左右、与 3/9 点中线对齐；当前半日文字变金色， 胶囊填充仍 AM 橙红 / PM 淡蓝。
  • 金圈从 2px 起随加速日增厚到 10px，跨日 1s 平滑不消失；颜色走色谱， 外发光由 GPU shader 画。
  • 盘心没有 ×N；倍率值只在条右端出现一次，且只有 1–365 整数档。
  • 倍率条下方一行「现实 1 天 = 加速 N 天」，与当前倍率一致；拖到 365 档显示「加速 1 年」。
  • 页头左是日期（16/600 白色），右是农历/月相/财神；窗口高 ≥560 两行（第二行宜忌），<560 一行。
  • hover 日期弹周数/节日/节气；hover 右侧农历弹全部宜忌（每 5 条一行，位置固定）。
  • 「第 NNN 天」与当天时间同行：001 起补零，三位宽度固定不变。
  • 盘下没有农历 meta 行。

倒计时页

抽屉页。Hero 卡默认春节或用户点选的近期节日；用户自定义目标全部在下方列表；添加表单固定在页脚，目标再多也够得着。

抽屉内部

E2 Hero 卡 90.5px；默认春节，或用户点选的近期节日
E3 “下一个”标签 12/500 金色；不是页面标题
E7 近期节日行 11.5px 行盒；未来 5 个节日，金色可点，行盒底 +2px 画 2px 金线；固定不滚
E9 目标行卡 50.0px（2×10 + 名称 15.5 + 5 + 日期 9.5）；三列：名称/日期、剩余、垃圾桶；列表视口唯一滚动内容
E12 目标行删除 14×14；贴右、垂直中心对卡中心；与时间列间隔 10px；两步武装（Check，4s）
E15 抽屉页脚 固定 101.5；标签 11.5 + 5 + 输入 19.5 + 10 + 按钮 35.5 + 20
E16 名称字段 固定盒：label 11.5 + 5 + 输入 19.5；11.5 文字盒上下各 4px

E18 添加按钮 宽 88；高 35.5；ink 实底；不是金色

目测检查点

  • Hero 默认春节或点选节日；用户目标全部在下方列表。
  • 3 个目标时页脚仍固定可见；内容只在自己的滚动区滚。
  • 删除第一次点击变 Check（武装态），第二次才删除。
  • “近期节日”是 5 个金色可点项，点击替换 Hero。
03

世界时钟页

抽屉页。固定 hero：城市名 + 大号 24 小时时间 + 日期周几 + 「+8 时区」；下方城市列表可滚动；底部固定搜索框与“搜索”按钮。 hero 城市不在列表重复；hover 行出现 pin（删除左侧），点击替换 hero。

抽屉内部

F1 世界时钟页 页头“世界时钟”；坞标签“世界”
F2 Hero 固定时区 城市名 + 大号 24h + 日期周几 + 时区偏移
F3 城市行 名称 + 英文/时区副行 + 走时；hero 不进列表
F4 Pin 固定 hover 出现，删除左侧；点击替换 hero
F5 城市删除 Trash；两步武装；hero 无删除入口
F7 昼夜图标 Sun / Moon，14px；行宽 ≤280 跳过
F8 滚动套件 渐隐 + 金三角 + 4px 浮钮；与倒计时共用
F9 添加/搜索页脚 字段 + 搜索按钮；内容底边 20px
F10 搜索候选弹层 每条两行：中文 + 英文 + 日期/当地时间；第二行大陆/国家/admin1/时区/N 万；整行 hover；最多两条固定高
F11 世界空态 “还没有其他城市 / 从下方搜索…”

目测检查点

  • Hero 两行：城市名 + 大号 24h；日期周几 + `+8 时区` 偏移。
  • Hero 城市不出现在列表；hover 行 pin 在删除左侧，点击替换 hero。
  • Hero 不能直接删；先 pin 新城市，旧 hero 回列表后删除。
  • 底部搜索支持中文/英文/拼音；多结果先选后加。

天气页

抽屉页。整页 ScrollArea，没有固定页脚。头行是城市 + 刷新；下面是错误/旧值、Hero 聚簇、三列指标、逐小时曲线、七日范围条、数据源。

抽屉内部

G2 天气头行 城市 + 刷新/加载
G3 城市下拉 150px；切换即刷新
G4 刷新按钮 Refresh 16px；加载时换 Spinner
G5 加载弧 16px、270°、600ms/圈；替换 G4
G6 错误行 danger 12px；说明原因
G7 重试 小按钮；强制刷新
G8 旧值提示 “显示上次数据 X°”
G9 Hero 聚簇 图标 + 温度 + 描述
G10 天气图标 34px；按 WMO code
G11 温度 40px digits
G13 三列指标 体感 / 湿度 / 风力
G15 逐小时区 标题 + 曲线 + 图外时间轴
G16 温度曲线 132px；无背景/轴；4 条淡线
G19 七日区 周范围 + 7 行
G21 七日行 23.5px；日期 / 条 / 低高
G25 低/高值 68px 右对齐；在 card_bg 上
G26 数据源行 Open-Meteo · 免费接口

目测检查点

  • 七日温度绝不在金色条上；值列固定 68px，右缘不裁。
  • 曲线没有矩形背景/边框；只有 4 条横向淡线。
  • 失败时旧值仍显示，错误行有“重试”。
  • 整页可滚；没有固定页脚，不要找“页脚”。

闹钟页

抽屉页。快捷添加是有边界的 chip；闹钟行按时刻/开关行高计算：开关、24px 时刻、标签·重复、删除；添加表单固定在页脚。

抽屉内部

H2 快捷添加标签 12/500 muted；不是分区标题
H3 快捷 chip 27.5px；有边界；不是通用 chip 组件
H4 闹钟行 46.0px；开关/时刻/标签·重复/删除
H5 闹钟开关 layout.switch_w/h；on=success 绿
H6 闹钟时刻 28px digits；关闭时降权
H7 标签 / 重复 16px；超宽省略 + tooltip
H8 闹钟删除 16px Trash；两步武装
H10 闹钟页脚 标签 + 时间 + 添加；无错误行
H11 标签字段 Field；label 上置
H12 时间字段 HH:MM；非法不发送
H13 添加按钮 宽度 token / 高度计算 ink 实底

目测检查点

  • 开关 on 是语义绿，不是品牌金；位置在右才是主信号。
  • 快捷 chip 有 1px 边界；不应是裸文本或金底 hover。
  • 关闭的闹钟整行降权，但仍可读、可重新开启。
  • 删除第一次点击变 Check，第二次才删除。

怎么把这些名字用在对话里

一条对账描述只需要三段：位置、元素、状态，再加现象。位置从大到小，用 > 分隔。 

页面/区域 > 子区域 > 元素 [状态]：现象

时钟页 > 星盘 > 现实针 [常态]：长度只有金针的 62%，看起来像短线
倒计时页 > 抽屉页脚 > 添加失败 [错误]：在「目标时刻」标签行右端显示「输入错误！」，按钮位置不变
天气页 > 七日 > 低/高值 [常态]：值在 card_bg 上，不压金条
闹钟页 > 闹钟行 > 开关 [开]：绿色 + 旋钮在右；位置是主信号
设置页 > 动效 > 减少动效 [开]：hover/列表脉冲/toast 直取终态
先认区域，再认元素。说“主仪”就不要再补“时钟页左边”；说“抽屉页脚”就不要说“底栏”。
同一页的两个文案要说明。“世界时钟页（坞项‘世界’）”比单说“世界页”清楚。
状态用方括号。[悬停]、[聚焦]、[武装]，不要用“点亮/高亮/激活”这类模糊词。
视觉缺陷说“现象”，不说“感觉”。“七日低温值被右缘裁掉”比“天气有点挤”可复现。
旧称保留在对照表。旧截图/旧报告里出现“侧栏/底栏/浮窗”时，用 §09 的表翻译，不要直接改历史记录。
新元素先登记。新增可见元素先在 u.UI_GLOSSARY.md 写主称、代码锚点、尺寸/状态，再写代码。
维护规则：改名时同步代码 /// 注释、w.study.md 3.7 节、README 使用说明、u.UI_GLOSSARY.md 与这份指南；不要只改一处。 术语表不替代设计评审，它只保证我们指同一个东西。
