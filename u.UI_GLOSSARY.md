# AccelWorld UI 术语表

> 基线：**V0.6.4.1 / HEAD `5b0b2da`**（PL019 后）。行号会漂移，本表锚点用**文件 + 函数/组件名**，不用行号。
> 配套：根目录 **`u.UI_MAP.html`**（六页标注图 + 术语索引 + 状态词 + 令牌速查，浏览器直接打开）。
> 用途：用户目测 ↔ 代码 ↔ 文档三方对账。描述问题时建议统一写成：
> **`页面/区域 > 子区域 > 元素 [状态]：现象`**
> 例：`时钟页 > 星盘 > 现实针 [常态]：长度只有金针的 62%，看起来像短线`
> 例：`倒计时页 > 抽屉页脚 > 时刻字段 [错误]：红字把添加按钮挤下去`
> 原则：**一个东西一个主称**；括号内是代码名/英文名；别名只用于听懂，不用于写文档。

## 12. 状态词表（L）

描述任何控件时，状态词只用这一组：

| 状态      | 推荐写法                | 含义                               |
| --------- | ----------------------- | ---------------------------------- |
| 常态      | `[常态]`                | 无 hover / focus / press。         |
| 悬停      | `[悬停]` / `[hover]`    | 指针在命中域内；底色/边框变化。    |
| 聚焦      | `[聚焦]` / `[focus]`    | 键盘焦点；亮白 1.5px 环。          |
| 按下      | `[按下]` / `[press]`    | 指针按住；主按钮内缩。             |
| 选中      | `[选中]` / `[selected]` | 当前页面/当前项；坞用金下划线。    |
| 开启/关闭 | `[开]` / `[关]`         | 仅开关；不要用“选中”描述开关。     |
| 武装      | `[武装]` / `[armed]`    | 两步删除的中间态；Trash 变 Check。 |
| 加载      | `[加载]`                | Spinner/更新中；不是空态。         |
| 空        | `[空]`                  | 无数据；虚线空态框。               |
| 错误      | `[错误]`                | 红字/红缘；说明原因与下一步。      |
| 禁用      | `[禁用]`                | 不可交互且视觉降权；当前较少使用。 |
| 减少动效  | `[减少动效]`            | 设置开启后的直取终态。             |

**不要用的模糊词**：`点亮`、`高亮`、`激活`（除非指 enabled/active 的代码语义）、`选中态`（开关请说开/关）、`闪一下`（说具体元素与时长）。

## 15. 对账写法示例

- `时钟页 > 星盘 > 现实针 [常态]：短、灰，长度约金针 62%——这是设计，不是缺失。`
- `时钟页 > 盘下读数 > 日序号 [常态]：只有 ≥24h 才出现“第 2 天”；1 天内不显示。`
- `时钟页 > 倍率条 > 倍率值 [常态]：只有条右上一个 ×7.2，盘心没有。`
- `倒计时页 > Hero 卡 > 剩余大数 [溢出]：目标名很长时，数字应收号到 0.5 下限而不是压住日期。`
- `倒计时页 > 抽屉页脚 > 错误行 [错误]：红字出现时添加按钮不应上下跳（错误行恒占 16px）。`
- `世界时钟页 > 城市行 > 基准标记 [常态]：左侧金线 + “基准” chip 同时出现；只靠金色不算达标。`
- `天气页 > 七日 > 低/高值 [常态]：值在 card_bg 上，不压金条；右缘不裁。`
- `天气页 > 逐小时 > 当前竖线 [常态]：只在最近小时 ±90 分钟内出现；超出不画。`
- `闹钟页 > 闹钟行 > 开关 [开]：绿色 + 旋钮在右；位置是主信号，颜色是辅助。`
- `设置页 > 动效 > 减少动效 [开]：hover/列表脉冲/toast 直取终态；抽屉本来就没有滑入动画。`
- `全局 > 仪器坞 > 世界项 [选中]：金下划线在“世界”下，页头写“世界时钟”——同一页的两个文案。`
