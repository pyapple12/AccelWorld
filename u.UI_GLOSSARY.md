# ACCELWORLD Clock（天宫时计）UI 术语表

> 基线：**V0.6.6.5（PL029 天气联动世界 hero、三列首块与自动刷新）**。行号会漂移，本表锚点用**文件 + 函数/组件名**，不用行号。
> **文字盒与盒子对齐以 `AGENTS.md`「文字盒与盒子对齐（强制基准）」为准**：盒高查 `font_profile` 公式（中文用 `trim_grids`；英文/数字用最大墨迹 + 上 0.2 + 下 0.1）；默认盒底对盒底，基线只在盒内（盒底 − `bottom`），外部对齐只用盒子数值；盒底不是裁切边界，真实字形下探可画出盒底，不裁切。
> 配套：根目录 **`u.UI_MAP.html`**（六页标注图 + 术语索引 + 状态词 + 令牌速查，浏览器直接打开）。
> 用途：用户目测 ↔ 代码 ↔ 文档三方对账。描述问题时建议统一写成：
> **`页面/区域 > 子区域 > 元素 [状态]：现象`**
> 例：`时钟页 > 星盘 > 秒针 [常态]：朱红细长带尾，比时针短一档的观感差是设计`
> 例：`倒计时页 > 抽屉页脚 > 时刻字段 [错误]：标签行右端出现「输入错误！」，按钮位置不变`
> 原则：**一个东西一个主称**；括号内是代码名/英文名；别名只用于听懂，不用于写文档。

## 12. 状态词表（L）

描述任何控件时，状态词只用这一组：

| 状态      | 推荐写法                | 含义                               |
| --------- | ----------------------- | ---------------------------------- |
| 常态      | `[常态]`                | 无 hover / focus / press。         |
| 悬停      | `[悬停]` / `[hover]`    | 指针在命中域内；底色/边框变化。    |
| 聚焦      | `[聚焦]` / `[focus]`    | 键盘焦点；亮白 1.5px 环。          |
| 按下      | `[按下]` / `[press]`    | 指针按住；主按钮内缩。             |
| 选中      | `[选中]` / `[selected]` | 当前页面/当前项；坞用金下划线。    |
| 开启/关闭 | `[开]` / `[关]`         | 仅开关；不要用“选中”描述开关。     |
| 武装      | `[武装]` / `[armed]`    | 两步删除的中间态；Trash 变 Check。 |
| 加载      | `[加载]`                | Spinner/更新中；不是空态。         |
| 空        | `[空]`                  | 无数据；虚线空态框。               |
| 错误      | `[错误]`                | 红字/红缘；说明原因与下一步。      |
| 禁用      | `[禁用]`                | 不可交互且视觉降权；当前较少使用。 |
| 减少动效  | `[减少动效]`            | 设置开启后的直取终态。             |

**不要用的模糊词**：`点亮`、`高亮`、`激活`（除非指 enabled/active 的代码语义）、`选中态`（开关请说开/关）、`闪一下`（说具体元素与时长）。

## 15. 对账写法示例

- `时钟页 > 星盘 > 秒针 [常态]：朱红细长带尾；三针走现实，黄针才是加速——颜色不是状态，是分工。`
- `时钟页 > 盘下读数 > 日序号 [常态]：只有 ≥24h 才出现“第 2 天”；1 天内不显示。`
- `时钟页 > 倍率条 > 倍率值 [常态]：只有条右上一个 ×N（整数），盘心没有。`
- `倒计时页 > Hero 卡 > 剩余大数 [溢出]：目标名很长时，数字应收号到 0.5 下限而不是压住日期。`
- `倒计时页 > 抽屉页脚 > 添加失败 [错误]：在「目标时刻」标签行右端显示「输入错误！」，按钮位置不变。`
- `世界时钟页 > Hero [常态]：城市名 + 大号 HH:MM:SS + 日期周几 + 「+8 时区」；hero 不在列表重复。`
- `世界时钟页 > 城市行 [hover]：pin 图标出现在删除左侧；点击后替换 hero。`
- `天气页 > 第一块 [常态]：城市与温度同 title 28；英文名与描述同 body 16；三列内容各自水平居中；块高由第一列城市 CJK 盒 + 第二列描述 CJK 盒决定；36 图标盒中线 = 块中线。`
- `天气页 > 七日 [常态]：标题“七日天气预测”；标题下 10px；日期后 10px 接图标盒（边长=行高），剩余宽按 1:8:1 分给空隙与横线。`
- `天气页 > 七日 > 低/高值 [常态]：值在 card_bg 上，不压金条；右缘不裁。`
- `天气页 > 温度折线 [常态]：每小时圆点；温度只标 3/6/9/12/15/18/21，圆点上方 5px；无“现在”线。`
- `闹钟页 > 闹钟行 > 开关 [开]：绿色 + 旋钮在右；位置是主信号，颜色是辅助。`
- `设置页 > 动效 > 减少动效 [开]：hover/列表脉冲/toast 直取终态；抽屉本来就没有滑入动画。`
- `全局 > 仪器坞 > 世界项 [选中]：金下划线在“世界”下，页头写“世界时钟”——同一页的两个文案。`
